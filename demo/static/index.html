Document AI parses one document. Vertex AI Search indexes content that is already fit to index. Neither tells you what is sitting on a file share before you commit to migrating it. This does — across the whole estate, in one pass.

  1. Inventory & format health. Every file identified by its magic bytes, not its extension — so renamed, encrypted, corrupt and legacy files surface immediately.
  2. Deduplication. Exact copies by content hash, and the "FINAL v3 (copy)" near-duplicates by text similarity, with the storage that reclaims.
  3. Sensitivity. PII, PHI, financial and credential detection, checksum-validated, with optional Cloud DLP escalation on the riskiest files.
  4. RAG readiness. A score and a disposition per file, plus the Document AI processor each one would need.
